每一次 provider 计费调用发生即记录——token、费用、模型、会话；这些数据能在三处读回：侧栏「Token 用量」大屏、设置 → Token 用量，以及对话面板的「用量」页签。

## 你可以这样用

- **看总量**：大屏上是带费用的汇总卡片、趋势图（单日按小时、更宽区间按日，悬停看点位总量）与五页签明细区——**按项目 / 按模型 / 按会话 / 按供应商 / 运行开销**。日期区间与模型筛选两处共用，另有 `1d` / `7d` / `30d` 快捷区间；请求数卡片带「失败」与「开销」两个徽章。
- **按你关心的维度切开**：各行可按总 token 或费用排序（会话另支持最近活跃），项目行在截断前聚合全部匹配的顶层会话，运行开销页签按类别拆出标题生成、自动审查、推理翻译等辅助调用，供应商页签按路由键列出各自的缓存命中率与已计费用——两个入口各自记住自己的排序选择。
- **盯住单个会话**：对话面板的「用量」页签给出当前会话的数值卡、四项 token 明细条、趋势图与按模型表；「本会话 / 含子会话」一键切换范围，子会话表逐行钻取并可逐级返回，悬停失败胶囊看按类别明细。「最新请求」与「实时请求」还会在等待、生成、失败、取消时即时呈现，每次 provider 尝试各占一行。
- **看懂花了多少**：费用按模型单价逐条计算；点击有定价的模型名弹出完整价格表，按住 Ctrl 点击可只看该模型。过滤条行尾的「定价表」入口浏览云端定价的全部模型，其标题旁的「模型别名关联」管理本地的「模型别名 → 模型」关联。
- **盯住供应商配额**：输入栏模型选择器左侧的按钮跟随当前供应商展示套餐余量——套餐窗口、账户余额或剩余额度，Magpie 网关后面的每个上游账号都列出来。
- **调成顺手的样子**：宿主**插件页**里本插件的**配置卡**可改数据目录（保存绝对路径立即迁移历史）、「定价区域」下拉（Gitee / GitHub 镜像，同时决定 ¥ 或 $），以及**「常驻侧边栏」**——开启后入口移出「更多」菜单、成为左侧栏固定一行。

## 一些边界

- 未定价模型按 ¥0 计费并高亮提示；定价只来自启动时同步的云端镜像，手工编辑的 `pricing.json` 升级后不再读取。费率或规则变化后，费用从历史记录重新计算。
- 安装前的历史在首次启动自动补齐（幂等）；无法解析的会话日志跳过并计数。辅助调用无法回补——宿主不保存这些调用的用量记录，升级后的第一个请求才开始记录。
- 没有路由键的用量不并入任何命名供应商，而是单列成弱化的「缺失供应商」余量行（会话日志已删除、路由键字段加入之前的历史、标题生成等运行开销天然没有路由键）。
- 对话进行中保存新的数据目录会被拒绝，等对话结束再保存。移除插件后数据文件仍留在 `~/.dsh/token-usage/`，不需要时请自行删除。
- 不支持的供应商不显示配额按钮（火山方舟、ZenMux、智谱团队版、Claude / Codex / Gemini / Grok 官方订阅、GitHub Copilot）。
