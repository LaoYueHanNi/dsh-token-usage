## 连接、版本与证据要求

1. 遵循 skill：每个请求都有稳定的顶层 `session`；Windows 请求体通过文件工具或 Node REPL 的文件 API 写入唯一 UTF-8 JSON 临时文件，再用 `curl.exe --data-binary "@<绝对文件路径>"` 发送，返回后删除该请求文件。不要把中文 JSON 放进 shell 参数或管道。
2. 先 `list_browser_tabs`，按 URL 和标题确认 Harness，再 `attach_tab`。记录 tabId、URL、页面标题和连接地址；不要猜端口或误选其他用户页面。连接失败时按 skill 处理，不能自动 restart、stop、upgrade。不要自动关闭用户借用的标签页或调用 `close_session`。
3. `snapshot` 定位元素后使用最新 `@e` 引用进行 click／fill；DOM 变化或导航后重取引用。必要时用 `evaluate` 读取 href、title、computed style、尺寸；不要通过修改 DOM、伪造 fetch 响应或直接调用写接口代替操作。
4. 确认页面包含最新特征：绑定搜索框为空、未输入时无候选、没有“查看全部关联”。不符合时先记录可能的旧包／缓存问题；普通刷新后仍不符，不擅自重建、重启宿主或更换插件配置。
5. 记录浏览器缩放、视口尺寸、主题和页面所在位置。对关键状态截图后必须实际打开图片检查，不能只报告文件已生成。用宽、窄两个视口复核（建议约 1280px 与 900px）；优先 CDP 改视口并在结束后清除覆盖，不改变用户系统显示设置。
6. hover 用 CDP 真实移动鼠标到图标中心，必要时按 skill 开启／结束焦点仿真。原生 Esc／Tab／radio 键盘行为用 CDP 输入，合成 `KeyboardEvent` 不足以证明浏览器默认行为。hover 约 100ms 后应出现页面 `role="tooltip"` 浮层，截图并检查真实显示，不能只读取属性来判断；移开后消失。检查图标没有原生 `title`、computed cursor 为 `default`，键盘聚焦也显示提示。
7. 如采集网络，操作前 `network start`，在 `stop` 前读取必要的 detail；只记录与测试相关的接口、状态和必要字段，不复制凭证或其他会话内容。截图／报告不包含无关敏感信息。
