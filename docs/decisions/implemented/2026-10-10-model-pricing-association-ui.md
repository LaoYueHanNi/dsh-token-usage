# DR: 未定价位置的局部关联、来源管理与上游请求草稿

Status: implemented

## Problem

[关联后端](2026-10-10-model-pricing-associations.md) 已能保存名称引用、重算历史并报告生命周期，但没有界面入口，用户仍无法在发现未定价时选目标或撤销。按规范 ID 折叠后，还必须保留每个原始来源，避免自动和人工混合行隐藏人工选择；没有当前用量的失效或被接管关联也不能消失。

本条落实 [整体决策](2026-10-10-prefixed-model-normalize-and-local-map.md) 的第三阶段。三个阶段均已有实施记录，整体决策已转为 implemented；实现状态不代表合并 main 或发布，不改版本。

## Decision

> [!NOTE]
> 本决策中的识别详情列表、未定价行额外按钮、用量页面顶层管理入口、选择器布局及 Issue 草稿字段已于 2026-10-10 由 [DR: 未定价标签承接操作与定价表内的模型别名关联入口](2026-10-10-pricing-association-entrypoints.md) 取代；2026-10-11 同条记录进一步取代搜索预填、保存后停留、模型行展开来源管理、绑定页的多字段子串搜索及管理页逐条状态与编辑入口。

**就地选择，明确保存。** 设置页、会话用量页与费用详情共享 `PricingAssociationProvider` 和原生关联弹窗。点击橙色「未定价」标签先选择「关联现有模型」或「增加模型定价」，识别原因在此弹窗中按需显示；不再在用量页面列出识别详情或追加独立关联按钮。从任意名称进入都使用原始完整名作为后端来源，不把规范 ID 或去前缀候选当关联键。搜索初始为空，只在规范模型 ID 中按关键词做包含匹配，忽略大小写与输入首尾空格；别名和家族不参与绑定搜索。只请求本机不带用量筛选的全表与关联接口，不执行前端价格身份推断。

候选是原生 radio，用户显式选择唯一 ID 后才能保存；候选唯一也不自动选或写入。紧凑面板显示来源、搜索、候选、选定目标与绑定按钮，歧义和错误仍保留。完整预览通过「查看定价」复用 `PricingDialog`，时间区间、上下文档位、工作日峰谷都可查看；单价换算采用该次定价列表的货币和汇率，避免混用旧统计快照。保存说明简述历史和后续用量按目标计费，完整来源隔离契约不变。

**来源可见、全部条目可管理。** 有已保存关联来源的折叠模型行显示小问号，悬停列出各原始模型 ID。「模型别名关联」入口集中在定价表标题旁，空用量窗口也可先打开定价表进入；列表不受当前日期、模型或会话筛选限制。管理页每行左侧显示映射，右侧提供撤销，不常驻状态说明或编辑入口；active、automatic-takeover、target-missing、pricing-unavailable 各状态的保存条目都保留。绑定页仍显示已有来源的状态，自动接管时不能覆盖自动结果；目标失效可从未定价标签重选。撤销需在面板内确认，并说明仍有自动结果时继续定价。

**错误不假装成功。** 加载失败可原地重试，候选请求失败时已有关联仍可查看和撤销；无有效价格时不能保存，存储故障或迁移暂停时禁止变更。写入前携带读取的 revision 与 directoryToken，响应成功且结构有效才关闭绑定页；撤销成功仍在管理页提示。失败保留搜索和选择，不自动重试；修订冲突采用返回的真实当前状态，要求再次明确提交。目录冲突丢弃旧目标与预览，重新读取新目录的关联和候选。正在写入时禁用重复提交、关闭、切换来源与撤销取消；Esc / 背板也不能中断显示中的提交，避免把仍在途的写操作伪装成取消。

原生 `<dialog>` 提供焦点限制与键盘行为，Esc / 背板关闭遵循已有弹窗约定，拖选后释放到背板不误关。规则详情关闭事件只处理自身目标，不能误关外层关联面板；关联面板的 Esc 不传播给费用详情弹层或定价表。关闭恢复进入按钮，进入行已因重算消失时退回定价表入口或同区域有效按钮。来源切换与重试取消旧读取，过期响应不能套到另一来源。

**保存后的刷新。** 成功保存／撤销发出本窗口 `token-usage:pricing-associations-changed`，各已挂载用量视图沿用原查询刷新，包含 chip、详情、自身费用与子会话。设置页的弹窗状态跨统计 loading / error 分支保留，日期与模型筛选不被清空；会话范围与子会话分组不变。服务端仍负责识别、RateKey 重选、费用、折叠与总览已用 ID，前端不改原始记录或构造费用。页面或弹窗卸载后不更新自身异步状态；已成功的在途提交仍通知其他挂载视图。

**仅生成上游草稿。** 未定价操作弹窗提供 `https://github.com/LaoYueHanNi/model-price-table/issues/new` 新标签页链接，关联选择器不重复此入口。使用 URL / URLSearchParams 编码标题和正文，设置 `noopener noreferrer`。英文标题为 `Add model pricing: {modelId}`，正文包含可选四项 token 价格与上下文窗口参考、可选官方定价地址、自动填充的 feed 版本。名称只作为标题文本，不注入 HTML；链接不自动提交，不带 API key、用量、会话内容或项目路径。关联、定价总览及统计响应的可选 `feedVersion` 支持草稿版本信息，不参与费用指纹或增加总览模型行。

本条部分取代 [模型名定价入口](2026-09-10-bymodel-pricing-name-affordance.md) 的未定价纯展示／无来源徽标约定，以及 [定价总览](2026-09-05-pricing-table-overview.md) 的响应完全不含版本元信息约定；已有已定价名字入口、一模型一行、筛选与搜索解耦继续有效。自动匹配三阶段、大小写规则、[后端生命周期与迁移保护](2026-10-10-model-pricing-associations.md) 都不改变。

## Alternatives considered

**先去全表找模型或手写 JSON。** 会打断当前筛选和会话上下文，且保存／撤销不可发现；未定价处直接选择，并单独管理全部持久条目。

**搜索唯一结果就自动保存。** 子串搜索不足以确认模型身份，也可能选择同家族的其他版本；radio 选择与明确保存是两个独立动作。

**折叠行只显示目标名字。** 自动和人工来源可能混合，甚至来源被上游接管；保留来源、状态与逐项管理，避免隐藏人工决策。

**冲突后自动用新修订号重试。** 会覆盖另一页面的选择或使用新目录里的旧预览；读取真实状态后由用户重新确认，目录切换另行清空候选选择。

**直接提交 Issue。** 上游请求需要提供商和价格依据，此处只有名称识别信息；只打开草稿，让用户补充并决定提交。

## Consequences

自动识别失败的补救具备可发现、可审阅、可撤销的完整交互，价格仍唯一来自 feed。中英文文案齐全，真实零价候选可选择。组件测试覆盖搜索、显式写入、完整规则预览、失败与冲突、停用与失效管理、键盘／层叠弹窗／焦点，以及安全草稿编码；页面集成测试覆盖原筛选和会话树保留、折叠来源、总览已用标记、chip 和详情刷新。原始用量、依赖版本与锁文件、插件发布版本不变。

同窗口事件只刷新已挂载组件，其他窗口在自身下次读取时获取新状态；并发写入仍由后端 revision 校验。上游草稿只提供识别依据，无法代替用户核验模型实际身份和提供商价格。候选价格变化或目标移除最终仍由提交时的服务端当前 feed 校验，无法保证浏览期间上游不变；原始历史缺失时依然隐藏无法可靠重算的金额。
