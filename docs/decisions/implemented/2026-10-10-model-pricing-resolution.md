# DR: 统一模型自动识别与带定价指纹的历史重算

Status: implemented

## Problem

提供商前缀和上游 v110 `aliasPatterns` 无法通过原有精确字典识别；子串匹配会混淆 `glm-5.3-flash` / `glm-5.3-flashx` 等不同身份。识别必须贯通历史费用、模型折叠与筛选、会话汇总、详情和总览「已用」。旧 rollup 保存了按旧模型规则选择的 `RateKey`，只换单价不能还原新规则下的时间区间、上下文档位和工作日峰谷。

本条实施 [整体提案](../proposed/2026-10-10-prefixed-model-normalize-and-local-map.md) 的第一阶段；手动关联后端现由第二阶段实施记录承接，界面及 Issue 草稿入口现由 [第三阶段实施记录](2026-10-10-model-pricing-association-ui.md) 承接。

## Decision

> [!NOTE]
> 本决策中的仅自动解析及 feed-only 上下文契约已于 2026-10-10 由 [DR: 未定价模型的本地关联后端与迁移保护](2026-10-10-model-pricing-associations.md) 部分取代。自动链顺序不变，失败或歧义后才使用完整来源的人工关联；上下文与指纹包含关联内容。

**设置卡片支持立即同步定价表。** 「定价区域」下拉框右侧的按钮调用无参数 `POST /token-usage/pricing-sync`，宿主按当前已保存配置解析镜像 URL（显式 `pricingUrl` 仍优先），复用启动／切区同步的 feed 校验和原子写盘。手动调用不受启动宽限或自动合并延迟限制；同一目录和 URL 的在途同步共享 Promise，失败后可重试。接口仅接受同源 POST，响应不缓存；写盘成功后返回版本和模型数量，网络／校验／磁盘失败返回 502，迁移或配置变化返回 409。写盘前重新校验目录 epoch 和当前目录／URL，过期下载保留旧镜像。

按钮在同步中、只读、保存中、迁移中或有未保存修改时禁用；未保存修改提示先保存或放弃，避免下拉草稿与实际镜像源不一致。成功显示版本与模型数并发送本窗口 `token-usage:pricing-table-changed`，已挂载用量视图沿用原筛选刷新，已打开定价总览重新读取。失败明确提示并保留旧表；只有结构有效的成功响应才发刷新事件，组件卸载后不更新自身状态。在未安装新宿主接口时同样显示失败，不伪造成功。

**统一自动识别入口。** `src/model-resolution.ts` 在全表逐阶段匹配：原始完整名称的 modelId → 历史 aliases；原名没有命中时，取各段非空的 `/` 路径最后一段，重复 ID → alias；均无命中才将原名与去前缀候选交给 aliasPatterns。原名优先于去前缀，ID 优先于 alias，同阶段歧义停止，不继续寻找另一价目。

三个阶段都忽略大小写：精确比较用 `toLowerCase()`，正则固定使用 `i`。这是本插件明确的大小写及 provider 前缀兼容扩展，上游默认仍区分大小写且不去前缀。原始名和正则源码保留原貌，不 trim，不移除版本、flash/flashx/fast/mini/max 等身份；前导、尾随或连续 `/` 不生成候选。正则必须有 `^` / `$` 且匹配覆盖整个输入，拒绝尾部换行带来的 `$` 例外。

**加载校验、编译，按快照缓存名称结果。** 正则限于上游可移植字面量、转义标点、分组、alternation 和 `?`；空分支、重复正则、非法/不支持语法和忽略大小写后重复 modelId 使整份 feed 无效。即使某行单价无效会被既有清洗逻辑丢弃，其身份也必须校验。同模型命中去重，跨模型保留候选并报歧义。同步先校验，再原子替换；失败保留旧镜像。`readPricingContext` 对未变化的文件内容复用编译好的索引，源内容变化后替换上下文。

**一次请求使用同一上下文。** `PricingContext` 提供识别、规范名、完整规则、详情用 pricing 字典和汇率快照。逐请求选规则、费用层、筛选、请求序列和会话折叠共同消费这个入口。byModel 按规范 ID 折叠；未识别名称按完整原名忽略大小写分组，展示一个原始拼写，不同 provider 保持独立。原始 JSONL、rateRows / byHour / bySession 的模型名保持原样；零单价仍是已定价。总览保持一个 feed modelId 一行，已用标记来自服务端折叠后的 ID。

**rollup 是可失效派生状态。** 新增 `pricingFingerprint` 与 `sourceFiles`。SHA-256 指纹包含识别算法版本、可用性、模型 ID、历史 aliases、正则和实际规则（含 weekday、窗口、档位、价格及槽顺序）；排除版本号、更新时间、family、label 与仅影响展示换算的汇率。指纹缺失或变化时重读冻结原始文件，重新选择 RateKey；时钟回拨时已吸收文件仍参与重建。汇率从相同快照读取，其变化不需要重选 RateKey。

同目录 rebuild 和历史同步的失效删除共用串行队列，避免临时文件互相踩踏和失效后旧写入复活。发布 rollup 前检查目录与当前 feed 指纹；过期快照可以完成自身响应，但不能覆盖新快照缓存。队列覆盖本宿主进程内读写，不提供跨进程锁。

**费用可用性是显式契约。** 统计提供 `modelResolutions`（原名、状态、规范 ID、命中方式、去前缀情况和歧义候选）及 `costState`：ready / pricing-unavailable / history-incomplete。chip 带费用状态、定价不可用原因及关联存储故障，按需 session 详情才带识别明细。镜像不可用原因分为 missing / unreadable / invalid-json / invalid-feed。各视图隐藏不可用金额，用量仍可查看；正常表的未命中、歧义单独告警，并通过第三阶段的关联入口提供人工选择或上游草稿。

重建检查文件清单、读取/解析完整性和旧累计用量是否能恢复。无法完整重算时不发布新 rollup，保留可用旧聚合与新记录；金额占位为 0，但通过 costState 隐藏，不把旧 RateKey 套到新模型伪造费用。会话和子会话从保留的 bySession 单元恢复用量；缺失的逐请求时间戳和小时粒度无法由聚合还原，请求序列只显示可读取记录。旧 rollup 仅缺会话维度时保留累计用量并强制重建，无法凭空恢复会话归属；其他结构损坏仍从可读原始文件恢复。

本条部分取代 [别名折叠](2026-09-10-bymodel-folds-pricing-aliases.md) 的碰撞、未定价分组和无需重建约定，以及 [daysOfWeek](2026-08-29-daily-slots-days-of-week.md)、[会话维度](2026-09-05-session-dimension-rollup.md) 中更新规则可直接沿用旧身份的假设和旧会话缓存的兼容策略；三层规则、原始模型名和会话维度仍有效。

## Alternatives considered

**仅在重启或切区时刷新价格。** 上游更新或首次同步失败时需要人为重启，区域选项无法直接表达重试；设置卡片增加手动同步入口，继续复用同一云端来源。

**浏览器直接下载并提交定价表。** 这会重复镜像选择、feed 校验和写盘保护，也让客户端持有组合层 URL；浏览器只发送无参数 POST，由宿主解析当前生效配置。

**contains 或首条命中。** 已有 flash / flashx 的实际碰撞，费用会随数组顺序变；子串只适用于候选搜索，不用于计费。

**只在归一化时忽略大小写。** 同一名称的大小写会改变精确和正则结果，违背用户约定；三个阶段统一处理，同时保留完整身份。

**沿用旧 RateKey，只换费率和规范名。** 旧未定价记录可能遗漏目标时间规则、档位和槽位，规则调整也可能改变身份选择。指纹变化后重新解析原始记录，以重建成本换取正确性。

**先做手动关联界面。** 关联会产生依赖识别结果的写状态及操作入口；本阶段先交付自动链，关联文件、并发修订和交互分别独立实施。

## Consequences

识别、计价、折叠、筛选和各视图口径一致，大小写不改变模型，错误或歧义不猜价格。用量事实、发布版本和依赖锁文件保持不变。测试覆盖阶段优先级、身份隔离、非法 feed、旧汇总升级、历史规则重选、并发重建/失效以及费用不可用的界面。

规则或身份变化后的首次读取需要重建冻结聚合，耗时随历史增长；缺失源记录时主动放弃可靠金额和无法恢复的时间粒度。每次读取仍需检查镜像与关联内容，编译和名称结果在内容变化时重置。手动关联后端已实施，操作界面和上游 Issue 草稿入口现由第三阶段实现，整体提案继续为 proposed。
