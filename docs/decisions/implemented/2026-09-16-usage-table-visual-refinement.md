# DR: 用量统计表格视觉降噪与微交互调优

Status: implemented

## Problem

设置页与会话抽屉中的用量明细表格（`TokenUsageSection`、`SessionTable`、`UsageView`）存在几处细节体验痛点：

1. 未发生读写的 Token 单元格直接显示高亮纯白的 `0`，多行多列的大面积白字 `0` 形成视觉噪音，掩盖了真正产生缓存读写的关键数据；
2. 8~9 列的高密度纯数字表格缺乏行级悬停反馈，用户横向扫视时容易看串行；
3. “费用”作为用户最关心的核心产出指标，与过程指标字重完全一致，缺乏视觉焦点；
4. 表头与数据行使用相同底边线，在粘性吸顶滚动时，表头与数据行界限偏弱。

## Decision

在 100% 保持原有原生紧凑布局（保留 4px 6px 严格内边距与原版成功/失败列结构）的前提下，对三处用量表格收敛以下细节微调：

- **0 值视觉弱化**：输入、输出、读写缓存为 0 时赋予 `.zeroDim`（弱灰文本 `--dsw-alias-label-tertiary` 与 0.55 透明度），降低背景杂音，凸显活跃读写数据；
- **行级微弱悬停**：`tbody tr:hover` 增加 `var(--dsw-interactive-bg-hover)` 与 0.12s 平滑过渡，辅助横向扫视视线对齐；
- **费用列字重聚焦**：费用单元格统一应用 `.costCol { font-weight: 600; }`，字色保持纯白，主次层级分明；
- **表头分界微增强**：`th` 字重设为 600，下边框升级为 `1.5px solid var(--dsw-alias-border-l2)`，稳固定界感。

## Alternatives considered

- **卡片化、分层表头与彩色胶囊进度条** —— 破坏原有工具界面的极简克制感，增大视觉负荷。
- **放大单元格 padding 与强行占位成功/失败列** —— 窄面板（~500px 视口）空间预算非常紧凑，放大间距或改变轨道会导致网格挤压和文字重叠，必须保持原有 4px 6px 紧凑内边距与原版布局。

## Consequences

- 换来：表格视觉信噪比明显提升，核心开销一眼可见，横向扫视不易错位；设置页与会话抽屉表格体验统一。
- 代价：样式模块新增 `.zeroDim` 与 `.costCol` 两个轻量属性类。
