# DR: 未定价标签承接操作与定价表内的模型别名关联入口

Status: implemented

## Problem

模型识别详情区重复列出未定价名称，模型列额外追加的「关联已有模型」按钮又超出固定列宽，遮挡请求数等后续列。全局关联管理放在用量页面顶部，与定价表入口分离，增加页面噪声。

## Decision

设置中的 Token 用量统计页移除卡片下方的未定价汇总警告条，避免重复列出模型名称及「费用按 0.00 计」文案。按模型表继续保留橙色「未定价」操作标签和未知费用的 `—`，存储故障、定价表不可用与历史不完整提示继续显示。

本条部分取代 [局部关联界面](2026-10-10-model-pricing-association-ui.md) 的识别详情列表、未定价行额外按钮、用量页面顶层管理入口、模型行展开来源管理、绑定搜索复用定价总览搜索规则及管理页逐条状态与编辑入口。识别、关联存储与完整价格规则不变。

用量页面与费用详情移除模型识别详情列表和未定价行的额外关联按钮，保留存储故障、定价表不可用及历史不完整提示。橙色「未定价」标签成为原生按钮，保持紧凑尺寸及名称省略布局，支持键盘焦点。点击打开小型原生弹窗，显示原始名称，并提供「关联现有模型」和「增加模型定价」两项操作。普通未命中不再重复显示「未找到对应定价模型」；有歧义时仍显示具体候选原因。

前者转入紧凑关联选择器，后者在新标签页打开上游 Issue 草稿，不自动提交。进入选择器使用服务端原始完整名称，大小写折叠行不会把显示拼写误当成另一来源。关闭操作弹窗恢复标签焦点；保存后标签消失则回到定价表入口或同区域的有效按钮。

关联弹窗宽度上限为 480px，标题 14px，正文与提示以 12px 为主，来源名 13px；不依赖宿主默认段落与标题字号。管理说明为「模型别名与模型的本地映射」，空态为「无数据」，两者使用相同提示样式。绑定页保留来源、搜索、radio 候选与明确绑定按钮，压缩说明，选定模型的完整价格通过「查看定价」按需展开；无结果时不显示空候选框。自动歧义、关联状态、错误和撤销确认仍显示，但不再重复普通未命中原因或增加模型定价入口。

绑定页不提供「查看全部关联」跳转；全部条目由定价表入口管理。打开绑定页时搜索框为空，不带入无法匹配的未定价名称；空输入（含空白）不展示候选，也不提示无结果。修改搜索会清空旧选择，避免误保存已隐藏的目标。有效写入成功才关闭绑定弹窗并通知统计刷新；失败／冲突保持弹窗，撤销仍留在管理页。

绑定搜索只在定价表 `modelId` 中按关键词做包含匹配，忽略大小写并去除输入首尾空白，支持部分 ID；不查 aliasPatterns、family、规则或其他字段，不执行正则或提供商前缀推断。提示为「搜索模型 ID」。此前输入 `m` 会因 Claude 隐藏别名的 `medium`／`max` 返回看似无关的 Claude 候选，此规则保证命中依据就在候选显示的 ID 中：`m` 可找到 `MiniMax-M3`，不会仅因 Claude 的隐藏别名而命中。唯一结果仍需显式选择和绑定。定价总览继续使用自身的浏览搜索规则。

统计模型名旁只显示 14px 问号图标，不使用可展开的文字徽标。使用宿主 `Tooltip` 显示「此模型含手动关联：[原始模型 ID]」，hover 延迟为 100ms，键盘聚焦无延迟，正文 12px，取消额外渐入动画。移除原生 `title`，鼠标为普通指针而非 `help`，避免光标再出现一个问号及浏览器不可控的长等待。同一折叠行的多条关联来源完整列出，包含已保存但停用的来源；原始名称来自服务端解析，不能由显示的规范模型名反推。图标可聚焦且具有完整可访问名称。提示以固定定位留在当前组件树内，使费用详情原生弹窗中也能显示，不挂到 `body` 的顶层弹窗之外；宿主处理视口边缘位置，长来源名可换行。映射查看与撤销由定价表内管理页承接。

Issue 入口仅位于未定价操作弹窗，英文标题为 `Add model pricing: {modelId}`（模型 ID 取原始完整名称）。英文正文只包含三个编号项：可选价格参考（币种、输入／输出／缓存读／缓存写的每百万 token 价格与上下文窗口 token 数）、可选官方定价 URL、自动填充的当前定价表版本；无版本时为 `Unknown`。不再携带提供商后缀候选、识别状态或歧义候选。名称经 URLSearchParams 编码并只出现在标题，不拼接 HTML。

全局管理入口移至「定价表」弹窗标题右侧，名称及管理弹窗标题统一为「模型别名关联」。管理弹窗嵌套在定价表内，关闭自身不关闭定价表，关闭后恢复标题旁入口焦点。即使用量为空、价格列表加载失败或定价表不可用，入口仍可打开全部持久关联；条目不受用量和定价搜索筛选影响。

管理列表每个映射占一行，左侧为「来源 → 保存目标」，右侧只有「撤销关联」。采用可收缩的文字列与固定按钮列，长模型 ID 在左列换行，不遮挡右侧按钮。移除管理页的逐条状态说明与「查看／修改」入口；各种生命周期条目仍完整保留，撤销仍带原始来源键和 revision／directoryToken 并要求确认，确认说明按需在该行下方展开。候选加载失败不在纯管理页显示候选错误；存储不可用、迁移暂停等真实写入限制继续提示。更换映射可撤销后从未定价入口重新绑定，绑定页保留自身的状态与冲突处理。

统计刷新期间保留定价表及其关联弹窗的位置与实例，避免撤销触发刷新时把二级页面卸载。已有关联来源图标、明确绑定／撤销确认、冲突保护、规则预览及当前筛选继续保留；绑定成功主动关闭关联弹窗。

真实浏览器复核按 [Chrome 人工复核任务](../../testing/2026-10-11-pricing-browser-review.md) 分为只读界面、可恢复关联写入、Issue 草稿与定价同步三组。共享数据的写入串行执行，并记录恢复状态；缺少页面、数据或故障条件时标记 BLOCKED／NOT RUN，不计为通过。组件断言不能代替真实 hover、键盘、草稿表单及网络链路证据；用例随界面变化更新，历史报告保留当时实现的结论。

## Alternatives considered

**扩大模型列以容纳额外按钮。** 占用统计列空间，窄窗口依旧受限；复用已有未定价标签即可提供入口。

**点击标签直接进入关联选择器。** 用户还可能需要向上游增加价格；先提供两个明确操作，避免把选择器当作唯一修复路径。

**关闭定价表后打开关联管理。** 会丢失当前搜索、模拟 token 和展开状态；嵌套管理页面可保留浏览上下文。

**预填来源名并在空搜索时列出全部模型。** 未定价名称通常无法匹配，用户要先删掉预填内容；空态列出全表增加选择噪声。由用户输入关键词后才展示候选。

**在统计行展开来源和管理按钮。** 多行内容撑高统计行，重复管理入口；小图标保留来源提示，详细管理集中于定价表。

**继续使用 ID、别名及家族子串搜索。** 隐藏别名中的 `medium`／`max` 会匹配 `m`，结果行却仅显示无 `m` 的 Claude ID，用户无法理解命中原因。搜索限定到显示的规范 ID 字段。

**完整 ID 相等才命中。** 用户输入 `m` 时无法逐步找到 `MiniMax-M3`，要求提前知道完整 ID，搜索体验过于严格；ID 字段内的包含匹配既支持查找，也排除其他字段的隐藏命中。

**原生 title 配合 help 光标。** 浏览器控制显示延迟，等待较长，光标还会追加第二个问号；原生气泡也无法由页面截图捕获。复用宿主提示组件统一速度、样式与键盘交互。

**每条映射下方常驻状态和编辑按钮。** 重复的「手动关联正在生效」与多行操作增加列表高度，简单映射表不需要常驻详情。列表仅保留映射和撤销，确认说明按需展开。

**只依靠组件测试完成交互验收。** 组件测试无法确认原生弹窗层级、真实鼠标提示及 GitHub 草稿填充；补充可分发的浏览器任务，并明确数据恢复和未覆盖项。

## Consequences

模型行保持紧凑，识别原因只在用户点击时出现，全部关联集中在定价表内管理。组件与页面测试覆盖标签入口、Issue 编码、原始名称、表头入口位置、空态、焦点恢复以及撤销后的双层弹窗保留。

关联选择多一次操作弹窗点击且需要输入模型 ID 关键词；无法靠别名或家族字段查找，最终目标仍需用户核验。全局管理需先打开定价表。费用详情和会话用量页可从未定价标签绑定具体模型；关联图标仅提示来源，不提供修改按钮。管理页聚焦查看映射和撤销，不直接编辑，也不常驻逐条生命周期说明；改绑需要撤销后重新绑定。
