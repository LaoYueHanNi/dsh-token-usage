# DR: 未定价模型的本地关联后端与迁移保护

Status: implemented

## Problem

完整自动识别无法覆盖内部代号与跨模型歧义；用户指定已有价目后，所有历史与后续用量必须使用该目标的完整规则。关联还涉及磁盘保存、并发页面、目录切换、上游删除和自动接管，不能把名称选择当作第二份价格来源，或在迁移时静默丢弃用户选择。

本条实施 [整体提案](../proposed/2026-10-10-prefixed-model-normalize-and-local-map.md) 的第二阶段。关联操作界面、来源标记与 Issue 草稿现由 [第三阶段实施记录](2026-10-10-model-pricing-association-ui.md) 承接。

## Decision

**独立保存名称引用。** 当前数据目录新增 `pricing-associations.json`，严格格式为 `{version:1, revision, associations:[{sourceModel,targetModelId}]}`。修订号是非负安全整数，仅接受声明字段；名称非空且无换行、控制字符，完整来源忽略大小写后唯一，保留展示拼写，不去前缀或 trim。文件不存在是空表、revision 0；不可读、非法 JSON、未知格式或重复来源使人工关联不可用，保留原文件并拒绝写入。自动识别仍可工作，统计带 `associationStorageError`，设置、会话及费用详情提示存储故障。

**自动结果优先、目标仅为当前 feed 的 ID。** `PricingContext` 同时读取 feed 与关联，完整自动链失败或歧义才应用完整来源的人工选择，返回 method `manual`、保存条目和原自动结果。目标只按忽略大小写的真实 modelId 校验，不能是历史 alias、正则名称或另一条关联。状态为 active / automatic-takeover / target-missing / pricing-unavailable；自动接管保留条目、自动目标及是否与原选择不同。自动失败后有效关联重新生效；目标删除或改名不追踪 alias，同 ID 只改大小写仍有效。保存不能覆盖唯一自动识别；撤销允许没有有效 feed，撤销后重新执行自动链。

**专用本机接口。** `/token-usage/pricing-associations` 支持 GET 读取全部条目及可选 `sourceModel` 的解析，POST 保存，DELETE 撤销。列表不受用量筛选影响。写请求仅接受 JSON，流式读取上限 64 KiB；只提交完整来源、保存时的目标、revision 与 opaque `directoryToken`，不接受路径或价格。沿用现有 `sec-fetch-site` same-origin 校验（兼容未提供该头的本机调用），限制方法，所有响应 `no-store`。冲突 409 和存储不可用 503 返回机器错误码及可读的当前状态；其他校验错误 400/413/415，磁盘操作失败 500 不返回成功。

**读改写并发保护。** `src/pricing-associations.ts` 的进程内按绝对目录队列串行化上下文读取、关联写入与定价镜像提交。锁内重读、检查修订号、目录、当前 feed、目标及自动状态；同一修订号的并发变更仅一项成功。临时文件加 rename 原子替换，替换前再检查目录 epoch 与原文件内容，失败清理临时文件并保留旧文件。成功增加 revision，幂等保存／删除不增加 revision，但必须通过所有适用的守卫。目录切换和重启更新随机 token，即使 A → B → A，旧表单也不被接受。

**沿用历史重算。** 上下文指纹算法修订为 2，包含按完整来源／目标忽略大小写排序的关联内容；文件 revision 和纯大小写调整不改变费用身份，因此不纳入指纹。存储不可用与有效空表是不同状态。保存、修改、撤销、失效、接管与 feed 规则更新后沿用 [第一阶段](2026-10-10-model-pricing-resolution.md) 的原始记录重算，重新选择每次请求的时间规则、档位、工作日峰谷及 RateKey。费用、折叠、筛选、会话、子会话、详情字典和总览已用 ID 同用此解析；原始 JSONL 不改写。源记录不完整仍保留用量、隐藏可靠性不足的金额。

**迁移保护只加强关联文件。** 宿主在复制前暂停源／目标关联和镜像写入，排空已接受队列，复制、切目录与清理结束后恢复，异常也恢复。关联文件在删除目标 rollup 或复制其他文件前逐字节预检：目标存在且不同则报错中止，保留两边；相同可复用。新目标以排他复制创建并检查完整字节，源清理也仅允许完整相同内容。未知格式和损坏文件仍按原始字节迁移，不可读必须拒绝。其他文件保留既有目标同名优先、同尺寸清理策略。目录队列 epoch 阻止迁移前尚未完成的下载在迁移后写回旧目录；暂停期间启动的同步也拒绝提交，成功切换后向当前目录重新同步有效区域的镜像。

本条部分取代 [自动识别实施记录](2026-10-10-model-pricing-resolution.md) 的仅自动解析及 feed-only 上下文契约；三阶段优先级、费用状态与历史保护继续有效。[废除手工价格](2026-09-05-abolish-manual-pricing-json.md) 继续有效：本地仅保存 ID 引用，单价与完整规则仍唯一来自云端镜像，总览不新增关联价目行。

## Alternatives considered

**本地价格覆盖或关联链。** 前者重新引入整模型覆盖丢失时间／档位规则的问题，后者增加环和间接失效；直接引用已有 ID 保持单一价格来源。

**人工结果覆盖自动命中。** 超出未定价补救范围，且自动更新可能隐藏真正价目；自动优先并显式保留接管状态。

**只用文件 revision。** 目录切换后目标可能有同一修订号，甚至回到原路径；目录 token 必须参与写入校验。

**沿用普通文件迁移规则。** 目标优先及同尺寸清理会丢掉内容不同但长度相同的关联文件；关联采取字节冲突拒绝，其他文件策略不扩张。

**先提供完整关联界面。** 整体按用户批准的阶段交付；本次只实现后端及存储故障提示，操作交互与来源徽标在后续界面阶段落实。

## Consequences

关联具备重启恢复、保存、修改、撤销、冲突校验及生命周期状态；真实零单价仍属已定价，自动／人工来源折叠无重复计数。专项测试覆盖 schema、损坏文件、生命周期、HTTP、并发、失败恢复、目录 epoch、迁移字节保护和历史规则重选；宿主集成覆盖实际复制与冲突后的继续记录。原始用量、锁文件、发布版本不变。

保护范围是同一宿主进程；外部编辑在替换前有内容检查，仍不承诺跨进程文件锁或外部并发编辑下的事务隔离。上下文每次读取会检查关联内容，历史变化首次读取仍有重建成本；缺源历史无法恢复精确金额。局部搜索、保存／撤销按钮、关联来源徽标与 Issue 草稿入口已在第三阶段实施；本记录继续描述后端契约，整体提案继续 proposed。
