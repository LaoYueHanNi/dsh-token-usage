# DR: 模型别名统一使用 aliasPatterns 正则

Status: implemented

## Problem

model-price-table 已新增 `aliasPatterns`，并冻结旧 `aliases`。本插件虽支持正则计费，仍在精确别名索引、定价字典展开、总览搜索、接口和同步数量中消费旧字段，形成两套不同的别名口径。维护者要求本项目统一使用新正则字段，不再识别旧字段。

本条部分取代 [自动识别与历史重算](2026-10-10-model-pricing-resolution.md) 的旧别名阶段与指纹字段、[别名折叠](2026-09-10-bymodel-folds-pricing-aliases.md) 的识别阶段，以及 [定价总览](2026-09-05-pricing-table-overview.md) 的别名接口与搜索约定。历史重建、费用可用性、模型折叠和总览布局继续有效。

## Decision

**只消费 ID 与正则。** 加载器忽略上游 `aliases`，既不参与识别，也不转换为正则；原始镜像仍逐字保存。自动链为完整原名的 `modelId` → 有效 provider 路径末段的 `modelId` → 原名与末段的 `aliasPatterns`。保留大小写不敏感、完整名称匹配和 provider 兼容；不修剪原名，不剥离版本、`fast`、`mini`、`max` 等身份。同模型的多个正则命中去重，跨模型命中报歧义，不按数组顺序猜价。原名和末段的正则结果合并，不能以某条正则的先后位置消除冲突。

**保持严格正则校验。** 正则缺省为空数组，必须使用 `^` / `$`、字面量、转义标点、分组、分支和 `?` 的可移植子集，编译只添加 `i`。匹配跨度必须覆盖整个输入，拒绝尾部换行。重复正则、非法语法和大小写重复 ID 使整份 feed 无效；同步失败继续保留旧镜像。

字面量允许模型名称中的冒号，例如 v115 的 `^nemotron-3-super-120b-a12b:free$`。冒号在此处不是正则操作符，不能因字符白名单过窄拒绝整个合法 feed；仍拒绝非捕获组、lookaround、通配符、无限量词等超出可移植子集的语法。回归覆盖加载、大小写/provider 匹配、边界拒绝和同步写盘。

**所有读路径按同一身份解析。** `cloudToTable` 和 `PricingContext.table` 只预置真实 ID，通过惰性属性读取解析观察到的正则名称；规范名索引也在 `get` / `has` 时解析。正则不能枚举成有限别名列表，字典遍历只包含真实 ID 和已观察到的成功命中。费用、筛选、会话、详情和已用标记继续共享当前上下文。手动关联仍只引用真实 ID，自动结果优先。

**总览搜索使用输入文本匹配正则。** ID 与 family 保留大小写不敏感的子串浏览搜索；别名搜索将完整输入与已编译正则匹配，不在正则源码里查子串，也不把输入当作正则。客户端按模型快照缓存编译结果。绑定弹窗继续只搜索 ID，遵守 [关联入口设计](2026-10-10-pricing-association-entrypoints.md)，不搜索正则或 family。

**接口和历史同步改用新字段。** 总览模型行只携带 `aliasPatterns`，不携带 `aliases`；同步结果与日志使用 `aliasPatterns` 数量（规则条数，不是可匹配名称数量）。识别 method 移除 `alias` / `normalized-alias`。历史指纹算法更新为 3，只纳入 ID、正则、价格规则和本地关联等有效语义；旧 `aliases` 变化不再触发重建。旧算法汇总下次读取从原始记录重选费率，保留用量和源名称；原始记录不完整时沿用已有费用不可用保护。

## Alternatives considered

**继续先查历史 aliases，再回退正则。** 上游仍推荐此兼容顺序，但会保留本次要求移除的旧字段依赖，使旧别名掩盖新的正则冲突，本项目按维护者要求不采用。

**把旧 aliases 转为锚定字面量正则。** 可以保留旧名称覆盖，但仍隐式消费旧字段；正则配置删除某名称后，它可能被旧字段重新启用，不满足新字段作为唯一别名来源的要求。

**对子串或正则源码做模糊识别。** `medium` 等推理级别和 `fast` 等模型身份容易碰撞；子串仅供 ID/family 浏览搜索，计价和别名搜索要求完整名称命中。

## Consequences

所有别名路径只依赖 `aliasPatterns`，新规则直接贯通费用与浏览搜索；大小写、变体隔离、歧义保护和历史费用重算口径一致。

覆盖迁移的过程见 [v114 历史别名审计与 v115 复核](../../testing/2026-10-11-pricing-alias-coverage.md)。v114 曾有 58 个旧名称在本项目失去自动识别，另有 12 个完整名称仅靠 provider 兼容识别；上游 v115 补齐规则后，255 个历史别名及大写变体的完整匹配与本项目解析均恢复到原目标。该结果是定价表版本快照，不替代新版本的规则校验。

只在旧 `aliases` 中存在、尚无新正则覆盖的名称会变为未定价，可在上游补正则或通过本地关联解决。此行为是显式取舍，不自动迁移旧字段。本机接口字段随宿主与客户端共同更新，旧客户端需重新加载构建；首次读取旧算法历史可能需要重建。版本号及发布流程不变。
