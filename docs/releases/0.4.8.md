# 0.4.8

## 新增与修复

- 系统辅助模型请求首次进入账本：自动审查（每次工具调用前的授权审查）、会话标题生成、推理翻译等旁路调用此前完全绕过会话事件，统计与费用系统性偏低。现在通过 `llm/stream` 统一入口采集，成功的流按 provider 上报的 usage 计费入账。
- 辅助请求计入总额、趋势图、按模型表与成本底账，与真实账单同口径；它们不归属任何会话，按会话表与会话用量页签保持纯对话口径。
- 统计页明细新增「运行开销」页签：按自动审查 / 标题生成 / 推理翻译 / 其他类别汇总次数、费用与 token，类别行可折叠展开实际使用的模型明细，末行合计，无数据时显示空态提示。
- 新增 Command Code 配额适配器（[Issue #12](https://github.com/LaoYueHanNi/dsh-token-usage/issues/12)）：`*.commandcode.ai` 的自定义路由显示配额按钮，展示 5 小时 / 每周 / 每月三窗口与套餐名；月度额度按 `/alpha/usage/summary` 实时花销计算，永远与官方账单一致。
- 新增 DeepSeek 账号余额适配器：选中「DeepSeek 账号」分组的模型时，配额按钮展示充值余额与赠金余额（金额大于 0 时），数据与设置页「账号与余额」同一条来源；未登录时按钮保持可见并提示登录。
- 失败或取消的辅助请求没有计费 usage，不落数据、只记警告日志，避免拉低成功率分母。

## 升级说明

- 辅助请求的历史漏记无法回补：宿主不保存这些调用的用量，升级后的第一个请求才开始记录。
- 辅助请求分类依赖宿主提示词文本（`REVIEW_POLICY` 开头为自动审查、`Translate the following text` 开头为推理翻译）；宿主升级改文案时类别落到「其他」，数据不丢。
- `rollup.json` 新增 `auxRows` 字段；旧文件缺该字段读为空列表，无需重建。降级到旧版插件时，辅助行会被当作普通请求计入模型/会话统计，属已知偏差。
- 新增 `recordAux` 配置（默认 `true`，与 `recordCompaction` 并列），可一键关闭辅助请求采集。
- 每次工具调用会多写一行 JSONL（实测约为对话行数的 1–1.4 倍），介意可关闭 `recordAux`。
- 宿主依赖基线不变，继续使用现有 dsh `0.2.0-rc.1` 系列依赖约定。

## 验证

发布检查通过：类型检查、48 个测试文件／926 项测试、后端与客户端构建、54 条决策记录校验。

自动化测试覆盖：辅助请求采集与提示词分类、聚合口径（入总量/按模型、不入按会话）、运行开销页签交互与空态、日期/模型筛选联动、`auxRows` 磁盘兼容；Command Code 四端点查询、月度池计算、软失败降级与 auth 上抛；DeepSeek 账号钱包映射、未登录与失败载荷。
