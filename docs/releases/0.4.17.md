# 0.4.17

## 新增与修复

- 新增**设置面板 Token 用量扩展页开关**：插件配置卡在「常驻侧边栏」下方新增「在设置中显示 Token 用量」（`Show Token Usage in Settings`）复选框，对应 `Config.settingsSectionEnabled` volatile 布尔字段（默认开启，仅显式为 `false` 时关闭）。习惯使用侧边栏大屏的用户可关闭「设置 → Token 用量」扩展页以精简设置面板导航；开关采用与「常驻侧边栏」一致的暂存式编辑，保存后由 `syncEntries` 动态注销或恢复 `settings.section` 扩展页，无需重载插件，且不影响定价表同步（#18）。

## 升级说明

- 默认开启，既有用户升级后「设置 → Token 用量」扩展页保持显示，无行为变化。
- 关闭设置面板扩展页后，仍可通过侧边栏「更多」菜单或开启「常驻侧边栏」从主列大屏查看完整统计。
- 配置为可选布尔字段，数据目录与既有账本格式无变化。
