# 0.4.7

## 新增与修复

- 支持带提供商前缀的模型名称，例如 `z-ai/GLM-5.3`；模型 ID 与别名正则均忽略大小写，保留版本和模型变体，跨模型歧义不猜价格。解决 [Issue #10](https://github.com/LaoYueHanNi/dsh-token-usage/issues/10)。
- 未定价标签提供关联现有模型与新增定价草稿入口。关联仅引用云端模型的完整价目，本地持久化并支持撤销；绑定搜索只查模型 ID，成功后自动关闭并刷新统计。
- 在定价表内集中管理模型别名关联，统计行通过快速提示图标显示原始来源。新增定价入口打开英文 Issue 草稿，附可选价格参考、官方地址和当前定价表版本，不自动提交。
- 增加手动同步定价表按钮，提供进行中、成功和失败反馈，并刷新已打开的定价表与用量视图。整表校验通过后原子替换，失败保留旧有效镜像。
- 统一费用、模型折叠、筛选、会话及详情的识别口径；名称映射或定价规则变化后，从原始记录重新选择历史费率。
- 修复新版定价表中 `nemotron-3-super-120b-a12b:free` 等合法冒号名称导致同步失败的问题。

## 升级说明

- 上游别名统一使用 `aliasPatterns`，不再读取旧 `aliases`。仅有旧别名、尚无正则覆盖的名称会显示未定价，可向上游补规则或本地绑定已有模型。
- 自动识别顺序为完整原名 ID → 合法 provider 路径末段 ID → 原名与末段的完整正则匹配；自动失败后才使用手动关联。手动关联不覆盖已自动识别的模型，也不保存自定义价格。
- 历史定价指纹算法升级为 3，首次打开旧历史可能触发重建，耗时取决于历史规模。原始名称、token 和请求数不变；源记录不足时保留可用用量并隐藏无法可靠重算的金额。
- 本机接口的 `aliases` 字段改为 `aliasPatterns`，移除 `alias` / `normalized-alias` 命中方式。升级后重启宿主或重新加载插件，确保宿主与客户端使用同一版本的构建。
- 宿主依赖基线不变，继续使用现有 dsh `0.2.0-rc.1` 系列依赖约定。

## 验证

发布检查通过：类型检查、44 个测试文件／872 项测试、后端与客户端构建、51 条决策记录校验。npm 包版本、宿主／客户端入口、语言文件和文件白名单核验通过。

自动化测试覆盖 provider 前缀、大小写、正则边界与歧义、关联存储和迁移、历史费率重算、界面搜索与写入、定价同步。上游 v115 的 255 个历史别名及大写变体已核对到原目标。

浏览器分组复核未发现已确认缺陷；缺少数据或故障条件的 BLOCKED／NOT RUN 项不计为通过，测试边界见 [浏览器复核任务](../testing/2026-10-11-pricing-browser-review.md)。
