# 0.4.19

## 新增与优化

- **支持配置实时请求池保留条数（`requestPoolLimit`）**：
  - 服务端 `Config` 新增 `.volatile()` 配置字段 `requestPoolLimit`（默认 `20`，允许 `1–1000` 整数），`/token-usage/stats` 按请求实时读取最新上限并裁剪 `requestDetails`，保存后即时生效，不截断日志、汇总或趋势图；
  - 插件设置卡片「Token 用量」新增「实时请求保留条数」数字输入，默认占位提示 `20`，留空保存恢复默认；非法输入即时提示并仅禁用「保存」，保留「放弃」可用，且不阻塞「同步定价表」。
- **仪表盘视觉层次、微动效与共享表面模块**：
  - 抽出 `surface.module.css` 统一管理卡片边框、顶部表面高光、内阴影顶边与悬停提亮，状态强调色（费用/命中率）与最新请求氛围微光改用 `--dtu-surface-*` 变量调节；
  - 会话页、总页面与设置页接入共享 KPI 线性微图标、四桶语义色点、等高 Bento 卡片与按模型用量占比细条，并为进行中状态点、新请求到达与历史行增加遵循 `prefers-reduced-motion` 的微动效；费用胶囊详情面板同步补充线性图标，列表卡头控件补充悬停提亮过渡。
- **定价表模拟栏与预设芯片交互优化**：
  - 四桶输入胶囊接入共享表面并在桶标签内嵌语义色点，改用内容自适应分栏与固定基础宽度的输入框（弹窗宽放宽至 `780px`，`≤ 680px` 视口折为 2×2），修复长标签下缓存读/写输入框溢出遮挡；
  - `K/M/B` 单位切换改用内嵌圆角分段槽与浮动高亮药丸；预设案例按钮改为带场景说明（极高缓存／高缓存／翻译场景）与指示点的全圆角芯片。
- **重构中英文 README 首屏排版**：补充居中 Hero、内联徽章、能力速览表与供应商配额双栏展示，将迁移说明与细节收进折叠块。

## 修复

- **修复趋势图 X 轴长跨度偏斜分布下的刻度重叠**：`labelIndices` 改为按缩放后横坐标与文本估算宽度判重，在密集请求偏于一端、中间存在长空白时不再强行渲染索引中点，改为只展示安全净距内的有效刻度（或仅留首尾两点）。

## 升级说明

- 数据目录结构、账本格式与既有限额默认行为（请求池默认 `20`）完全向后兼容，升级无需迁移。
