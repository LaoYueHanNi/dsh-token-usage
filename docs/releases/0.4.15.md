# 0.4.15

## 新增与修复

- 修复**费用动效把输入区顶飞**：会话底部胶囊的费用数字每次上涨都会弹一下，同时飞出一枚 `+Δ` 标签。标签画在胶囊之下——而 composer 被宿主钉在窗口底边，于是这枚标签离开了输入区的盒子，落进对话滚动容器的可滚动溢出区。宿主跟随对话尾部滚动时按「内容高度」定位，只扣掉了消息区的占位、没扣这枚标签，滚动位置因此被推过内容末尾约 40~55px；输入区底边原本正好齐着视口底边，粘性定位没有余量可吸收这段多出来的溢出（粘性只会往上拉、不会往下推），于是胶囊与输入框整体上浮、底部留出一条空隙。思考中与多轮请求每次费用上涨都会触发，问题反复出现。
- **整条 `+Δ` 标签链路移除**，费用动效只剩数字自身的一次缩放加染色。顺带说明：这枚标签原本向下飞，而输入区永远贴着窗口底边——它其实常年画在窗口之外看不见，唯一能被看见的时刻恰好就是上面那个 bug 露出的缝隙；移除后费用动效零溢出、零覆盖。
- 弹跳强度口径不变：按该步的 token 增量算强度（缓存未命中率权重 55%、输出量权重 45%），映射缩放峰值 1.08–1.32、染色 0–55%、时长 1000–1800ms；reduced-motion 用户仍只静默更新数字。

## 升级说明

- 界面行为变化只有一处：费用上涨时不再有 `+Δ` 标签飞出。费用数字本身的弹跳、面板里的总额与分摊明细、统计口径全部不变。
- 输入区不再被费用动效顶飞。此前若见过「胶囊与输入框整体上浮、底部留空」，升级后消失。
- 弹跳峰值仍可能让数字在最强时探出胶囊圆角约 2px（纯绘制，不参与布局），这是有意保留的观感项。

## 验证

发布检查通过：类型检查、59 个测试文件／1179 项测试、后端与客户端构建、84 条决策记录校验。

自动化测试覆盖：费用胶囊在用量变动后刷新数字且不再挂任何标签元素；面板懒加载读数、分摊与按模型明细、可见性规则维持原覆盖。
