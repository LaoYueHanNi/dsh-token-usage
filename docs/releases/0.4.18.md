# 0.4.18

## 新增与修复

- **子会话表展示团队模式、外部子代理与悬停语义名**：从 `subagent/catalog`、`subagent/descriptor` 与 `team/mode` 自有事件折叠子代理语义名、委托描述、生命周期模式与团队模式并写入 `sessions.json`（新增 `upsertMany` 批量落盘）。用量页签「子会话（N）」表首列优先展示简洁的委托描述，语义名、子会话 id 与生命周期模式移入悬停第一行；血缘根开启团队模式时在区块标题旁展示「团队模式」徽章；外部子代理列于本地行之后并弱化不可钻取，数值列合并提示「外部执行，不计入本地账本」并计入总数；表头与数据行高度统一锁定为 `26px`。
- **对齐 DSH 0.2.2 运行时与客户端构建协议（双兼容）**：
  - 客户端 `apply(ctx, config?)` 优先读取并订阅宿主投影的 `SyncedConfig`（`sidebarPinned`、`settingsSectionEnabled`），消除侧栏与设置页入口首帧异步闪烁，旧宿主自动降级回 `configForms`；
  - 目录迁移守卫与 `/token-usage/dir-guard` 优先读取 `ctx.agents.turnBoundaryOf` 投影缓存，无该服务时以自有 `turn/start`/`turn/end` 增量追踪并自动清理已移除会话，彻底消除运行时 `@deprecated` 的 `session.snapshotEvents()` 全量事件拷贝；
  - 客户端构建产物通过 `outputOptions.footer(chunk)` 输出标准 `meta.stylesheets` 交由新宿主 `DocumentStyles` 统一挂载与卸载清理，同时保留旧宿主 `ctx.effect` 兜底挂载与 `dispose` 清理，消除卸载与热更新样式残留及构建 sourcemap 告警。
- **补充插件矢量图标与引擎兼容声明**：新增 36×36 自包含用量仪表盘矢量图标 `icon.svg`，在 `package.json` 补充顶层 `icon` 字段、将 `icon.svg` 收录至 `files`，并显式声明 `engines.dsh` 为 `>=0.2.1-rc.3`。

## 升级说明

- 最低宿主版本要求保持 `0.2.1-rc.3`，所有 DSH 0.2.2 新特性均采用运行时探测与降级，旧宿主行为零退化。
- 既有数据目录如需为历史子会话补全子代理语义名、外部子代理与团队模式标记，请在插件设置页手动执行一次「全量扫描同步」。
- 数据目录结构与账本格式向后兼容。

## 验证

发布检查通过：类型检查、64 个测试文件／1360 项测试、后端与客户端构建、100 条决策记录校验。

自动化测试覆盖：子代理身份与团队模式折叠/渲染与 26px 行高、`SyncedConfig` 优先同步与降级、零快照 Turn 追踪与 `turnBoundaryOf`、构建产物 `meta.stylesheets` 与旧宿主卸载清理、插件图标与 `engines.dsh` 元数据校验。
